# 港鐵大富翁 3D · MTR Monopoly 3D

以香港港鐵為主題的 **3D 立體大富翁**。擲骰沿路綫前進，買入車站、升級上蓋物業、抽乘客消息、搭機場快綫飛站，集齊三條路綫成為路綫之王。

## 遊戲特色

- **立體棋盤**：Three.js 打造的金屬金邊棋盤、40 塊霓虹車站牌、中央全息路綫圖、環繞列車、浮塵粒子與 bloom 光暈
- **港鐵角色棋子**：車長、站長、工程師、乘客四位 3D 角色，各有制服、配件與被動專長
- **8 條路綫 / 23 個車站**：荃灣綫、觀塘綫、港島綫、東涌綫、屯馬綫、將軍澳綫、東鐵綫、南港島綫
- **搭車元素**：轉綫站免費轉乘、機場快綫 HK$800 任意飛站
- **罰款與事件**：票價調整、突擊查票、維修費、遺失行李、颱風停駛、訊號故障等 14 款乘客消息
- **上蓋物業**：月台 → 商舖 → 上蓋物業 → 摩天塔，獨佔整條路綫車費 ×2
- **服務延誤**：被扣留 2 回合，可付 HK$800 提早出閘
- **車費池**：所有罰款累積，停在車廠可全數獨吞
- **繁忙時間**：第 8 回合起全綫車費 ×1.5
- **3 個 AI 對手**：會自行買地、升級、搭車與判斷是否付錢出閘

## 角色與專長

| 角色 | 被動能力 |
| --- | --- |
| 車長 | 駛經香港站額外 +HK$400 |
| 站長 | 買入車站 9 折 |
| 工程師 | 上蓋升級 75 折 |
| 乘客 | 每次抽乘客消息 +HK$200 津貼 |

你可以在開始畫面選擇角色，其餘三位由 AI 操作；你選擇的角色會先手。

## 操作

- **拖曳** 旋轉棋盤
- **滾輪** 縮放
- **停留車站** 查看車費表、業主與升級狀態
- 按底部按鈕擲骰、買地、升級、結束回合

## 本機執行

```bash
npm install
npm run dev
```

開啟終端顯示的網址（預設 `http://localhost:5173`）。

## 部署到 Vercel

這是一個標準 Vite 靜態專案，Vercel 可以自動辨識：

1. 在 [Vercel](https://vercel.com/new) 匯入此 GitHub repository
2. Framework Preset 選 **Vite**（通常會自動選中）
3. Build Command：`npm run build`，Output Directory：`dist`
4. 按 **Deploy**

或用 CLI：

```bash
npm i -g vercel
vercel --prod
```

## 技術
